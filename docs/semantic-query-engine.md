# Semantic Query Engine

The semantic query engine converts a validated abstract plan into a trusted backend query. Gemini receives only relevant semantic metadata and returns a Zod-validated plan; it never receives SQL results or database rows.

## Runtime Flow

```text
User
  -> Gemini semantic plan
  -> Zod plan validator
  -> semantic resolver
  -> policy and confidence checks
  -> parameterized SQL compiler
  -> SQL Server
  -> deterministic presenter
  -> frontend
```

The engine rejects unknown entities, unmapped fields, blocked/restricted fields, low-confidence fields, unvalidated joins, raw SQL-shaped values, and limits above the hard maximum of 500 rows. Default limit is 100.

## Catalog Status

`semantic/catalog/schema.json` is generated by the admin-only `discover:semantic` scanner. It captures all accessible tables and views, columns, keys, indexes, foreign keys, SQL dependencies, and stored procedure metadata. It stores metadata and derived relationship information only, not row samples.

`semantic/catalog/semantic.json` is a conservative semantic seed based on validated application mappings and approved documentation. It is not a claim that all discovered objects are understood. Entity states are distinguished as discovered, cataloged, classified, mapped, queryable, or blocked.

Run the full scanner with:

```text
npm run discover:semantic
```

The command requires the trusted data-service SQL credentials and must run in the backend/admin environment, never in the AI runtime.

## Conservative Mapping

Purchase Request is currently a candidate entity with `UNKNOWN` confidence and is not live-queryable until its physical header/detail mapping and joins are validated. Inventory material-name joins remain unknown unless an approved join is added. The engine returns a mapping miss instead of guessing.

## Security

Semantic queries are backend actions. Gemini has no SQL driver, database credential, database connection, or result payload. All values are parameters. SQL mutation and arbitrary stored procedure execution are not supported.
